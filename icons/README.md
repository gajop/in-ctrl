# Icons

- `gcp/`: official Google Cloud product icons, from <https://cloud.google.com/icons>. Google provides them for drawing architecture diagrams.
- `cloudflare/`: Cloudflare product icons, from [cloudflare/cloudflare-docs](https://github.com/cloudflare/cloudflare-docs/tree/production/src/icons) (CC BY 4.0).
- Brand logos and generic shapes come from the `@iconify-json/logos` (CC0), `@iconify-json/devicon` (MIT) and `@iconify-json/lucide` (ISC) packages.
